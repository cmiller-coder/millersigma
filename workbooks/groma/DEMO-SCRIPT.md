# Groma NAV REIT demo flow

The story is deliberately simple: **trust the number → understand the building
→ act on the budget → govern the judgment → prove the tie-out**.

## 1. NAV Control Room — trust the number

Start with REIT NAV, raw TTM NOI, cash contribution, and look-through LTV.
Select **Seaport Residential JV** in the equity chart or holdings table.

In the drawer, show that its $26.8M mortgage exists at 100% but REIT debt is
$0. The mortgage sits inside the equity-method LLC, so REIT equity equals REIT
value. A naive ownership split would double-count debt and understate NAV.

Line: **“This is why treating every property identically is fast and wrong.”**

## 2. Property Scorecard — understand the building

Read the cash ladder left to right: Buildium income minus Buildium expense and
any explicit master-rent allocation equals raw NOI; then subtract cash interest
and recurring capex.

Highlight Broadway Lofts or Dudley Terrace. The master-rent allocation prevents
the naive account sum from overstating NOI. Select a row to retain the full
source and accounting context.

## 3. Property Budget App — act in the live system

Switch **Management scenario** between Current Plan, Lease-up Upside, and Cost
Pressure. Enter a property-manager forecast NOI or revised capex budget in a
peach cell. The portfolio NOI, budget remaining, management value sensitivity,
and property chart update immediately.

Set an owner/status, add a workflow comment, then click **Submit budget** and
**Approve budget**. Show the user and timestamp in approval history.

Line: **“The acquisition model now governs daily work instead of becoming a
forgotten quarterly spreadsheet.”**

The value output is a management sensitivity, not the external appraiser's
market view or a replacement for the approved valuation mark.

## 4. Capex Review — govern the judgment

Compare the $118k roof with the $94k gut renovation. The roof is recurring
because it preserves rentability; the renovation is value-add. Override a class
and show the cash contribution/AFFO deduction update.

Line: **“Dollar size is not the rule—the nature of the work is.”**

## 5. Controls & Lineage — prove it

Show the independent NOI, valuation, and debt checks. Then scroll to the
twenty-four-tab map: every decision surface has a named direct source and rolls
from the same Layer 1 property-quarter dataset.

Close: **“One refresh, one visible rulebook, one quarterly commit—and live
property decisions between quarters.”**

## Do not claim

- The synthetic figures are production Groma data.
- The management value sensitivity is the external appraiser model.
- The demo has connected to Groma's Buildium, ownership, loan, or NAV systems.
- The workbook replaces source-system permissions or financial close controls.
