Dashboard Theme Gallery

Five visual systems for the same forecasting command center, so you compare aesthetics rather than different content. Pick one per build; the data app and workflow stay the same.

End-user flow: 1. Customer name  →  2. Data app (forecasting, cohort builder, …)  →  3. Theme option 1–5  →  4. Build.
